One sentence, at most 200 characters, explaining the modern internet to a time traveler who has just stepped out of the year 1800 — built only from things a person from 1800 already knows (a road, a post office, a library, a market, a letter, a picture, a voice, ink), with no words coined after their time.

## Run it

```sh
python3 main.py
```

Writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline, so the file holds exactly the 172 characters the gate counts.
